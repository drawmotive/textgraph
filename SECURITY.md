# Security reporting

This policy covers the public TextGraph SDK, bundled runtime, optional fonts
and samples in this repository. Include the exact package version, OS,
Node/browser version, a minimal reproduction and the expected security impact.
Remove secrets and unrelated private data from reports.

If GitHub private vulnerability reporting is available for this repository,
use [Report a vulnerability](https://github.com/drawmotive/textgraph/security/advisories/new).
Availability depends on repository settings; this document does not assert
that the feature is enabled.

If that option is unavailable, contact project maintainer
[devmasonz](https://github.com/devmasonz) to request a private reporting
channel; do not post exploit details publicly. The maintainer profile is an
interim contact route. A dedicated private reporting contact has not yet
been confirmed.

Use the [public issue tracker](https://github.com/drawmotive/textgraph/issues)
for ordinary bugs and support questions without sensitive details.
